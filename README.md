## NeRF-based archaeological artifact reconstruction

**Project managed with uv**
for installation see :
https://github.com/astral-sh/uv

#### Setup :
**1.** Create venv :
```
uv venv
```

**2.** Activate venv :
```
source .venv/bin/activate
```

**3.** Install packages :
```
uv pip install -r pyproject.toml
```
